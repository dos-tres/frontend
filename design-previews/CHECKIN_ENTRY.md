# 생활 점검 바로가기 기능 패치

CSS만으로 버튼 동작을 바꿀 수 없어 별도 JSX/CSS 패치로 제공합니다. 현재 작업 폴더의 App·HomeLanding·MyPage를 기준으로 생성했으며 사용자 요청으로 현재 로컬 원본에 적용했습니다. 다른 체크아웃에 적용할 때는 변경 충돌을 확인합니다.

- 마이 홈: 미진행 표시 → 시작하기. 버튼 이름은 ‘생활 점검 시작’.
- 완료 후: 결과 보기. 기존 생활 점검 결과 화면으로 이동.
- 메인: 완료한 점검 기록이 없으면 대화 영역 바로 아래 안내 배너. 생활 점검으로 직접 이동.
- 마이 홈과 메인의 완료 판정을 완료 이력 존재 여부로 통일.
- 기존 메인 하단의 중복 처음 시작하기 안내는 새 배너로 대체.
- 파랑 실서비스 스타일을 기본 적용하는 패치는 포함하지 않음. 기존 스타일/미리보기 모두에서 사용할 수 있는 기능 변경.

```sh
git apply --check design-previews/checkin-entry.patch
git apply design-previews/checkin-entry.patch
npm run build
```

원복: `git apply -R design-previews/checkin-entry.patch`.

패치를 메모리에서 적용한 React 브라우저 모의 검증으로 시작 바로가기·완료 결과 버튼·완료 시 배너 숨김을 확인했습니다. 이후 사용자 요청으로 원본에 적용하고 실제 앱에서 메인·마이페이지 시작 버튼이 생활 점검으로 이동하는 것과 프로덕션 빌드를 확인했습니다.
