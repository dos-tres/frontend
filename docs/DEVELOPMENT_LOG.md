# 개발 기록

## 2026-11-19 · 마이페이지 복원 및 상태 점검 연동

- 브랜치: `feat/mypage-settings-checkin`.
- 이전 임시 작업본의 내 정보 수정·활동/관심 입력·지역 데이터/출처를 현재 저장소로 복원. 기존 홈·정책·센터·일정 화면 유지.
- 자가진단은 기존 프론트 전용 4문항 대신 백엔드 문항/요약 API 계약을 사용. 단일/복수 선택, 최대 3개, none 배타 선택, 건너뛰기, 재시도, 15초 요청 제한, 화면 종료 시 요청 취소 추가.
- 서버에 저장 API가 없는 개인정보/활동 정보는 메모리 유지. 백엔드 수정 없음. 추천/대화 화면은 예시 상태 유지.
- 검증: 프론트 빌드 성공, 백엔드 checkin 6개 및 recommend_api 5개 테스트 통과. 브라우저 연결 및 백엔드 포트 바인딩 제한으로 실제 데스크톱/모바일 연동 검증 미완료.
- `git fetch origin`은 DNS 연결 실패로 최신 main 확인 불가. 로컬 main `f643523`에서 분기. 커밋·푸시·PR·배포 미실행.

## 2026-11-19 · 마이페이지 시각적 일관성 수정

- 사용자 피드백에 따라 별도로 추가했던 마이페이지 색상/16px 본문 및 선택지/버튼 색상 덮어쓰기 제거. 기존 styles.css의 전역 토큰과 공통 컴포넌트 스타일 재사용.
- 기존 화면과 같은 너비, 제목 17px 섹션·13px 본문·12px 레이블, 2열 입력/모바일 1열, 하단 일반 저장 영역으로 정돈. 사용하지 않던 사이드바 CSS 제거.
- 참고: 고용24 회원정보 관리 안내 및 마이페이지 개편 안내의 기능 분류. 별도 사이트 색상/브랜드 복제 없음.
- 검증: npm run build 및 git diff --check. 브라우저 접근 호스트를 사용할 수 없어 실제 화면 QA 미완료.

## 2026-11-19 · 실제 백엔드 앱 연동 점검

- 사용자 요청 재확인: 화면 구현뿐 아니라 실행 중인 백엔드와의 기능 확인이 목적. 서버 시작은 다시 시도했으나 TCP bind 권한 거부로 종료.
- 실제 프론트 API 모듈 → 실제 FastAPI ASGI 앱 계약 검증 스크립트 추가. 응답 하드코딩 없음. 정상 9문항/전체 건너뛰기/skip, 잘못된 선택지/최대 선택/배타 선택 확인.
- 잘못된 응답 자료형 세 사례에서 백엔드 500 재현. 요청대로 백엔드 변경 대신 validate() 자료형 확인 예시와 재현 요청을 docs/verification/checkin-integration.md에 기록.
- 정상 자가진단 계약에는 백엔드 필수 수정 없음. TCP/프록시/브라우저 종단 간 검증은 환경 제한으로 미완료.

## 2026-11-19 · 서버 미연결 시 예시 자가진단 제공

- 사용자 요청에 따라 연결 오류/재시도 화면 대신 예시 문항 9개와 선택 답변 기반 예시 결과를 제공. 백엔드 문항 스냅샷을 프론트에 포함.
- 문항 조회 2초, 결과 조회 3초 제한. 실제 결과 요청 실패 시에도 입력 답변을 유지하고 예시 결과로 전환. 예시임을 상단과 결과에 명시하고 보관 결과에도 표식 유지.
- 실제 API 우선, 다음 진입에서 다시 연결 시도. 예시 모드는 서버 계산/저장을 하지 않음.
- 검증: npm run build, 예시 문항 수/선택 결과/건너뛰기/빈 답변/예시 표식 확인, 기존 실제 프론트 API → FastAPI ASGI 계약 검증 통과. 실제 브라우저 검증 미완료.

### 자가진단 안내 문구 정리

사용자 요청으로 화면의 예시 데이터 배너와 관련 안내 문구를 제거했습니다. 서버 미연결 시 로컬 문항/답변 기반 결과로 전환하는 동작과 내부 출처 표식은 유지합니다. 진단이 아니라는 안내와 새로고침 시 초기화 안내는 유지합니다. 검증: npm run build, git diff --check.
