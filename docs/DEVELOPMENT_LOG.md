카드 소개를 추가하고 여백을 줄였으며 국민취업지원 설명을 해요체로 정리했어요. 신청 화면의 3단계 표시와 보라색을 제거했어요. 구글폼 신청 경로가 있는 공고에서 신청 같이하기를 누르면 실패 화면 대신 팀 취업 테스트 폼을 바로 읽어요. 원래 공고와 시연 폼의 차이를 명시하고 실제 기관 접수로 표시하지 않아요. 입력 패널/새 질문이 보이도록 스크롤을 보완했어요. 실제 브라우저에서 자격 답변→신청 제안→첫 질문 연결을 확인했어요. 추가 제출은 하지 않았어요. FE 빌드 통과.

## 새 대화 카드 선택 상태 복구 (2026-11-23)

새 대화와 이력 전환 시 이전 추천 카드 선택을 비워요. 명시적인 찾아줘/추천 요청에서는 이전 공고 ID를 보내지 않아 카드 탐색이 막히지 않게 했어요. 기존 대화 이력·프로필·신청 구현은 유지하고 FE 빌드가 통과했어요.

## 내부 신청 시연·추천 답변·일정 대화 수정 (2026-11-23)

현재 FE 신청 완료는 실제 Google Forms 제출 요청 없이 local simulated 결과로 처리해요. 기존 API의 실제 제출 경로와 구분하며, 상단 안내 한 줄과 신청 시연 완료 문구를 사용해요. 선택 공고 제목으로 내부 문항을 작성하고, 개인정보 없이 대화의 사실을 가져와 추천 답변을 한 번에 만들고 수정할 수 있어요. 이전 실접수 1건 검증 기록은 당시 동작이며 현재 FE는 실제 전송하지 않아요. 일정 등록은 제목부터 대화로 묻고, 입력창 위 별도 버튼 묶음을 없앴어요. 일정 응답에 이전 신청 버튼이 붙지 않게 했어요. 브라우저에서 자격 답변/일정 제목 질문/AI 추천 답변/내부 시연 완료를 확인했어요. FE 빌드와 일정·치환 검증 통과.

## 프로필 입력 경고 위치 (2026-11-23)

프로필 형식/날짜 오류를 채팅 말풍선으로 추가하지 않고 입력 패널 안, 입력칸 바로 위 빨간 경고로 표시해요. aria-invalid와 설명 연결을 추가했고 입력 수정 시 경고를 지워요. 브라우저에서 잘못된 날짜 반복 입력에도 경고 1개만 유지되고 수정 후 사라지는 것을 확인했어요. FE 빌드와 profile-chat 검증 통과.

## 입력 복원·지역 확인·신청 화면 간소화 (2026-11-23)

이력 전환 전 진행 상태를 즉시 저장하고 질문 번호/큐/입력값/관심 선택을 복원해요. 필요한 정보 입력은 자동으로 열어 중간 복귀 시 다시 요청할 필요가 없어요. 띄어쓰기 없는 서울시 주소와 시 이름 생략을 정규화하며 구/동 불일치는 자동 저장하지 않고 정확한 지역 후보를 확인받아요. 브라우저에서 화면 이동·이력 전환·새로고침 후 강서구 천호동 입력 복원과 강동구 후보 확인을 검증했어요.

신청의 원문 대화/AI 프롬프트/자동 채운 정보 수정 버튼을 제거했어요. 추천받기 한 번으로 마스킹된 대화 사실만 보내 답변을 생성하고 결과를 편집해요. 최종 확인은 짧은 요약 표와 항목별 수정으로 정리하고 신청 중 별도 채팅 입력창을 숨겼어요. 데스크톱·모바일에서 최종 확인과 버튼이 한 화면 안에 들어오는 것을 확인했고, 실제 외부 제출은 하지 않았어요. FE 빌드, 지역/입력 검증, 개인정보 치환 검증 통과.


## 신청 후 일정과 대화 연결 (2026-11-23)

- 신청 완료 뒤 일정 등록은 신청일(KST)의 신청 기록을 즉시 저장하고 공고·로컬 대화를 연결해요. 시연 기록은 실제 접수와 구분해요.
- 참여·문의 날짜는 신청일과 별도 일정으로 표시해요. 맥락 없는 일정 요청에만 제목부터 질문해요.
- 검증: FE 빌드, verify-application-schedule / verify-schedule / verify-local-storage 통과. 브라우저에서 로컬 신청 시연 → 즉시 일정 등록 → 관련 대화 복원, 별도 참여일 등록, 맥락 없는 질문을 확인했어요. 데스크톱·모바일 화면을 확인했으며 외부 폼 추가 제출·배포는 하지 않았어요.


## 원본 구글폼 질문과 복제 폼 제출 (2026-11-23)

- 중구 진로 상담 신청은 임시 취업 클래스 대신 해당 원본 구글폼의 12개 질문을 표시해요. 체크박스 시간표, 기타 입력, 질문 설명, 문항별 수정과 초안 생성도 연결했어요.
- 최종 확인 뒤에는 서버가 문항 일치를 검증한 팀 소유 복제 Google Form에만 제출해요. 복제 경로 기본 채움은 가상 정보이고 한 줄 안내로 구분해요. 기관 원본에는 제출하지 않아요.
- 검증: FE 빌드·일정/로컬 저장 회귀, 실제 브라우저의 원본 문항 입력→최종 확인→복제 접수, Google Forms 응답함 0→1건을 확인했어요. 데스크톱·모바일 시간표와 최종 확인 표시를 확인했어요. 배포는 하지 않았어요.
