# 조이에 전달할 저장 정보

- App이 현재 personal/activity와 거부·건너뛰기 및 최근 관심 변경을 반영한 현재 생활점검 답을 조이에 전달한다. 과거 이력 전체를 합치지 않는다.
- 생년월일은 로컬에서 보관하고 생일 기준 만 나이로 변환. 거주 지역은 시군구 코드, 현재 상태는 백엔드 job 코드, 재학 상태는 school로 변환한다.
- 현재 생활점검 문항 답과 관심 분야는 checkin. 건너뛰기/답변 거부/미확인과 불필요한 임의 필드는 제외한다.
- 선호 참여 방식·모임 규모는 현재 프론트 조이의 참고 정보에 포함한다. 기존 /api/chat 계약에는 해당 필드가 없어 API payload에는 넣지 않는다. 추후 서버 context 계약 확장이 필요하다.
- 기존 /api/chat 형식의 buildAssistantChatPayload(messages, context)를 마련했다. 나이·시군구가 불충분하면 profile=null이며 필요한 정보만 이어서 물어야 한다.
- 이름·전화·이메일·생년월일 원문·과거 설문 이력은 이 payload에 포함하지 않는다. 신청 시 필요한 개인정보의 제공은 별도 흐름이다.
- 조이 화면 ‘참고하는 내 정보’에서 현재 정보를 볼 수 있으며, 저장 정보 확인/조건 안내에도 반영한다.
- 현재 실제 LLM 요청 경로는 미연결이다. payload 준비와 프론트 조이 전달을 외부 AI 전송 완료로 간주하지 않는다. 키 설정이나 외부 AI 호출은 하지 않았다.

검증: verify-assistant-context의 생일 경계·매핑·현재 답·거부 제외·연락처 제외·누락 정보 검사, 기존 profile-context 11건 ASGI 계약, 일정/센터 선택지 표시 회귀, 실제 Chrome 로컬 데이터→조이 확인, 빌드.
