## 3. 반반 화면의 의미와 프론트·백엔드 역할

기획 화면: **왼쪽은 조이의 대화·준비 내용, 오른쪽은 공식 신청 화면**. 확장 프로그램처럼 도와주는 느낌을 목표로 하되 확장 자체를 만드는 것은 이번 필수 작업이 아니다.

| 역할 | 담당과 범위 |
|---|---|
| 프론트 | 반반 배치, 현재 단계·다음 행동·추천 답변·일정 확인 표시 |
| 백엔드 | 허용된 신청 페이지의 문항 해석·답변 매핑·진행 상태 관리. 실행 기능이 있으면 허용된 입력·제출만 수행 |
| 공식 사이트의 사용자 브라우저 | 로그인·본인인증. 세션은 이 브라우저에 유지 |
| 사용자 | 직접 로그인·인증, 사실 확인, 서류 제공 여부 결정, 최종 승인 |

**둘셋 프론트의 상태·로컬스토리지에 외부 사이트 비밀번호·인증번호·세션 쿠키를 가져와 저장하지 않는다.** 백엔드 일반 DB·LLM·로그에도 전달하지 않는다. 사용자가 직접 로그인한 공식 사이트 브라우저의 세션과 둘셋의 회원 로그인은 별개다.

화면 URL만 바뀌었다고 로그인이 성공한 것으로 판단하지 않는다. 실제 페이지의 로그인 상태와 신청 화면 요소를 확인한 뒤 ‘로그인됨’ 상태로 전환한다. 확인할 수 없으면 ‘로그인 후 계속’을 눌러 안내를 이어가는 사용자 확인 방식으로 줄이고 자동 확인했다고 말하지 않는다.

외부 사이트가 iframe을 막거나 서로 다른 도메인 접근을 제한하면 프론트만으로 페이지를 읽을 수 없다. 준비된 전용 브라우저 연동이 없으면 공식 화면을 새 창으로 열고 조이는 단계 안내만 제공한다. **이 경우 반반 자동 연동 장면은 촬영에서 빼도 된다.**

## 4. 촬영 순서: 선택 영상 약 3분

| 시간 | 화면·행동 | 대사·설명 |
|---|---|---|
| 00:00~00:30 | 관악구·구직 상태와 생활 부담 설문 | “월세 지원을 알아보고 싶어요.” |
| 00:30~00:50 | 주거 정책 추천·공고 조건 | 조이: “저장된 조건을 먼저 비교하고, 추가로 확인할 조건을 정리했어요.” |
| 00:50~01:10 | 공식 신청 화면 열기. 가능하면 반반 배치 | “여기서부터 신청을 어떻게 하면 돼?” |
| 01:10~01:30 | 사용자가 공식 화면에서 직접 로그인. 인증 장면 녹화 제외 | 조이: “공식 사이트에서 직접 로그인해 주세요. 완료 후 현재 신청 단계를 확인할게요.” |
| 01:30~02:00 | 로그인 후 현재 단계·필수 항목 확인 | 조이: “지금은 서류를 준비하는 단계예요. 다음에 할 일을 정리해 드릴게요.” 실제 페이지가 그 단계일 때만 사용 |
| 02:00~02:30 | 필요 서류·소득 증명 발급 안내 | 사용자: “소득 증명은 어떻게 준비해?” → 실제 요구 서류명을 확인하고 발급 안내 |
| 02:30~03:00 | 준비 요약·달력 확인·일정 등록 | “11월 23일 저녁 7시부터 7시 반까지 서류 확인할 일정 넣어 줘.” |

이 정도로 영상이 끝나도 성공이다. 실제 정책 신청을 완료했다고 말하지 않는다.

## 5. 화면이 넘어갈 때 안내를 갱신하는 방법

1. 사용자가 공식 화면에서 다음 단계로 이동한다.
2. 연결 가능한 환경에서는 URL과 화면의 실제 단계 요소를 함께 확인한다.
3. 조이의 단계 카드에 ‘현재 단계 / 완료된 일 / 필요한 행동’을 갱신한다.
4. 로그인·개인정보·서류 화면은 필요한 비민감 항목만 해석하고 계정·인증 화면을 LLM에 보내지 않는다.
5. 자동으로 확인할 수 없는 화면은 사용자가 현재 단계나 필요한 문항만 알려주면 이어서 안내한다.

**사용자:** “로그인했어. 소득 증명서를 내라고 하네.”

**조이:** “화면에 적힌 정확한 서류명을 먼저 확인할게요. 발급 방법과 제출 전에 확인할 내용을 정리해 드릴게요.”

서류 안내 카드:

- 공식 화면에 요구된 정확한 서류명
- 해당 서류의 공식 발급처·발급 경로
- 공고에서 요구한 대상 연도·유효기간·파일 조건이 있는 경우 표시
- 발급은 사용자가 공식 화면에서 직접 진행
- 서류가 없으면 발급·확인 일정을 등록

‘소득 증명’이라는 말만으로 소득금액증명·건강보험료 서류 등을 임의로 정하지 않는다. 공식 공고가 요구하는 서류를 확인한 뒤 안내한다. 소득이 없다는 사실만으로 특정 서류 면제나 자격 충족을 단정하지 않는다.

## 6. 가능하면 추가할 신청 장면

**선택 조건:** 허용된 대상에서 실제 페이지 확인·입력·결과 확인이 모두 동작하고, 제출할 수 있는 테스트 환경 또는 명시적으로 허용된 신청이어야 한다. 이번 문서만으로 실제 기관 접수를 실행하지 않는다.

- 저장 정보로 초안을 채우고 모르는 필수 항목만 추가 질문한다.
- 긴 답변은 사실 기반 추천 답변을 제시하고 사용자가 수정한다.
- 최종 제출 내용·첨부 대상·동의를 확인한 뒤 “이 내용으로 신청할까요?”라고 묻는다.
- 승인 후 실행하고 실제 접수 결과를 확인한다.
- 성공한 경우만 ‘접수 완료’로 표시한다. 단순 화면 이동은 완료가 아니다.

완료 카드에는 확인된 신청 기간·참여 기간을 각각 구분한다. **기간 정보가 없다면 실제 접수 일시인 ‘신청일’만 표시한다.** 접수는 선정·지원 확정을 뜻하지 않는다. 제출이 지원되지 않으면 준비 내용과 공식 화면을 안내하고 일정으로 끝낸다.

반반 화면, 로그인 상태 판별, 외부 페이지 읽기가 연결되지 않았으면 해당 장면을 생략한다. 1번 구글폼 영상은 그대로 완결하며, 이 영상은 설문·정책 설명·준비 일정의 짧은 영상으로 줄이거나 통째로 제외할 수 있다.

## 8. 설문에 따라 추천이 달라지는 비교 컷

선택 영상에서 여유가 있으면 넣는 비교 컷이다. **나이·거주지·현재 상태를 그대로 유지하고 설문·관심만 바꾼다.** 다른 구 사용자와 비교한 결과만으로 설문의 효과라고 설명하지 않는다.

| 구분 | A: 주거·생활 부담 | B: 교류·문화 관심 |
|---|---|---|
| 프로필 | 만 25세·관악구·구직 중 | 동일 |
| economy | high | low |
| outing | mid | high |
| conversation | mid | high |
| face_to_face | mid | high |
| 관심 | 집·주거, 생활비·금융 | 사람 만나기·모임, 문화·여가 |
| 2026-11-21 실제 상위 정책 1 | 2026 청년 월세 지원 | 국립 문화시설 청년할인 |
| 실제 상위 정책 2 | 2026 청년주거 씨앗펀드 | 2026 청년예술청 운영 |
| 실제 상위 정책 3 | 2026 청년과 어르신 주거공유(한지붕세대공감) | 2026 7979 서울 러닝크루 |

정책뿐 아니라 프로그램 추천도 같은 프로필에서 달랐다. 기존 로컬 조회의 상위 프로그램 예시는 다음과 같다.

| A: 주거·생활 부담 설문 | B: 교류·문화 관심 설문 |
|---|---|
| 강서 11월 영테크 금융교육: 텅장탈출 | 관악 청년연합체육대회 |
| 관악 11월 1차 청년성장프로젝트 | 금천 기찻길 옆 북캉스 |
| 서초 공공주택정보 아카데미 | 강북 유스터마이징 |

프로그램 결과는 거주 구 안으로 제한된 목록이 아니다. 촬영 시 실제 갱신된 카드로 확인하고, 관악구 전용 결과라고 설명하지 않는다. 이 비교 컷은 1번 영상의 시작에 별도 삽입해도 되며, 반반 화면 구현과 무관하게 사용할 수 있다.

촬영 방법:

1. A 결과에서 프로필과 상위 카드 3개를 3초 이상 보여준다.
2. 생활점검·관심을 B로 바꾸고 저장한다.
3. 갱신된 결과의 이름과 추천 이유를 보여준다.
4. 내레이션: “같은 사용자라도 현재 상황과 관심에 따라 추천 우선순위가 달라집니다.”
5. 정책 안내를 이어갈 때는 A로 다시 저장한다. 비교 컷은 별도 시연 브라우저에서 따로 찍어도 된다.

순위·건수는 촬영 직전에 실제 API에서 다시 확인한다. 기존 화면이 남아 있거나 결과가 같으면 달라졌다고 설명하지 않는다. 이 비교는 여러 설문 값과 관심을 함께 바꾼 사례이며, 한 문항만의 효과라고 주장하지 않는다.

## 9. 촬영 우선순위

1. 필수 영상 1의 검증한 구글폼 신청 흐름을 먼저 완성한다.
2. 시간이 남으면 이 영상의 설문·정책 안내·준비 일정을 촬영한다.
3. 외부 화면 연동이 실제 동작할 때만 반반 화면·로그인 후 단계 안내를 추가한다.
4. 실제 정책 자동 제출은 필수 성공 조건으로 두지 않는다.

영상용 문장: “조이는 정책을 찾는 데서 끝나지 않고, 신청 화면에서 다음 할 일과 필요한 서류를 이해하고 준비하도록 돕습니다.”
