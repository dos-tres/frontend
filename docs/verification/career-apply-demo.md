# 취업 상담부터 테스트 신청·문의 일정까지

2026-11-23 로컬 검증. 배포와 실제 폼 제출은 하지 않았어요.

## 시연 순서

1. AI 비서에 “졸업하고 취업 준비 중인데 혼자 하니까 뭘 먼저 해야 할지 모르겠어.”라고 말해요.
2. “자기소개서도 막막하고 면접 경험도 별로 없어.” → “직접 피드백받을 수 있는 프로그램 찾아줘. 처음이라 사람이 너무 많으면 부담스러울 것 같아.”로 이어가요.
3. 비어 있는 정보만 입력해요. 가상 사용자: 23세, 서울 강동구 천호동, 구직 중, 학생 아님, 취업·진로/교육·자격증. 입력 완료 후 자동 탐색해요.
4. 실제 공고에 맞는 중구 1:1 진로 전문가 상담 카드와 설명을 확인해요. “여기서는 어떤 도움을 받을 수 있어?”, “취업 준비를 막 시작한 나도 신청할 수 있어?”를 물어봐요.
5. 신청 준비에서 실제 공고의 경로와 준비물을 확인해요. 별도 시연 예시의 팀 테스트 폼을 열어요. 이 폼은 베이킹 클래스이며 취업 공고의 실제 신청서가 아니에요.
6. 가상 정보만 사용해 자동 채움, 누락값 입력, 참여 동기 AI 전달 내용 미리보기, 초안 수정, 직접 동의, 최종 확인까지 진행해요. 실제 제출은 별도 승인 없이 누르지 않아요.
7. 마감 테스트 폼의 접수 불가 안내를 확인해요.
8. 실제 취업 카드로 돌아가 “자기소개서를 미리 써 가야 하는지 물어볼 말 정리해줘.”라고 말해요. 문의 일정은 날짜·시간·제목·장소 미리보기를 확인한 뒤 저장해요.
9. 메인 이동 → AI 비서, 새로고침, 새 대화 → 로컬 이전 이력 열기로 복원을 확인해요.

## 확인한 결과

- 실제 OpenAI 응답과 BE 추천 API로 위 취업 탐색과 선택 공고 질문을 확인했어요. 근거에 맞는 후보 1개를 반환했고 부적합한 문화 행사로 채우지 않았어요.
- 데스크톱과 390×844 모바일에서 카드, 말풍선, 선택지, 입력을 확인했어요.
- 열린 팀 테스트 폼을 읽어 최종 확인까지 진행했고, 마감 폼도 확인했어요. 외부 제출은 하지 않았어요.
- 문의 일정 미리보기와 확인 후 캘린더 저장을 확인했어요. 일정 중 다른 질문으로 전환할 수 있어요.
- 사용자 localhost 저장소는 지우지 않았어요. 브라우저 검증은 별도 127.0.0.1 출처에서 가상 데이터로 했어요.

## 데이터와 개인정보

프로그램 137개 중 127개를 원문 근거와 함께 구조화했어요. 원문 미확보 9개와 근거 검증 실패 1개는 추정으로 채우지 않았어요. 공통 BE 표시 데이터와 FE 오프라인 스냅샷을 맞췄어요.

추천·대화에는 필요한 나이와 시군구·상태만 전달해요. 신청 자동 채움은 FE에서 처리하고, 초안 요청은 이름/연락처 등을 치환해요. **최종 제출 시 답변 전체는 BE를 거쳐 Google Forms로 가요.** BE가 개인정보를 전혀 받지 않는 구조로 설명하면 안 돼요. 신청 답변은 로컬 대화 이력에 저장하지 않아요.

## 실행한 검증

BE unittest 143개 통과. FE 프로덕션 빌드 및 프로필/동 코드·개인정보 치환·로컬 저장·일정·생활점검 이력 검증을 실행했어요. 폼 문항이 변경되면 제출을 중단하는 회귀 검증도 포함했어요. 실제 제출 성공과 배포는 검증 범위에 포함하지 않아요.

## 취업 테스트 폼 실제 접수 검증 (2026-11-23)

AI 비서 → 시연 예시 → 취업 클래스 테스트 신청서로 열어요. 새로 만든 팀 소유 취업 클래스의 8개 필수 문항을 불러오고, 가상수아/23세/테스트 연락처로 참여 동기 AI 미리보기·초안 수정·직접 동의·최종 확인 후 1건 제출했어요. 사용자에게 링크 공개와 가상 제출 승인을 받았고, 서버 접수 결과와 Google Forms 응답 1개 및 내용 일치를 확인했어요. 기존 베이킹·마감 테스트도 유지해요. 실제 기관 신청과 배포·병합은 하지 않았어요. 이번 FE 빌드도 통과했어요.
