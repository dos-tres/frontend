# 센터·일정 최종 검증 (2026-11-21)

## 범위와 환경

- 실제 로컬 Vite 127.0.0.1:5173 → FastAPI 127.0.0.1:8000 → 프로그램 DB.
- Playwright를 프로젝트 밖 임시 폴더에 설치하고 시스템 Chrome headless로 확인. 사용자 브라우저와 분리한 새 컨텍스트 사용. 기존 사용자 로컬 데이터는 변경하지 않음.
- 데스크톱 1440×1000, 모바일 390×844. 실제 기관 신청·문의·로그인·폼 제출 없음. 조이의 제한된 일정 등록 동선만 확인하며 실제 LLM 연결은 범위 제외.

## 센터 정보 범위

- 서울청년센터 17곳: 공식 intro/notice 수집. 운영시간 17곳, 최근 공지 총 170건.
- 개별 센터 17곳: 기관/지자체 공식 소개 재확인, 이용 조건·시설·주소·링크 보완. 이 중 운영시간 12곳 확인, 9곳 공지 게시판 직접 링크 제공. 모든 기관의 게시판을 통합 수집했다고 표시하지 않음.
- 전체 운영시간 29/34곳. 미확인 5곳: 구로 청년이룸, 노원 청년일삶센터, 청년내일, 노원청년정책거버넌스센터, 종로청년창업센터. 시간은 추정하지 않고 행 숨김.
- 홈페이지 HTTP 오류/시간 초과/인증서 오류/블로그 프레임 등 제약은 공식 지자체 안내로 보완. 시설의 상시 이용시간과 개별 프로그램 진행시간, 입주자 이용시간은 혼동하지 않음.
- 프로그램은 DB 우선이며 센터 안내는 서버 파일의 확인된 사실 요약. 개인 데이터는 브라우저 로컬 저장.
