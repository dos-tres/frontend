# 센터 위치 카카오맵 보완

- 기존 공식 주소와 건물 단위 주소 검색을 우선 사용. 층수 제거 재검색도 유지.
- 주소 없음/구 단위 주소/주소 검색 ZERO_RESULT에 한해 JavaScript SDK Places.keywordSearch로 센터명·시도·구 검색. 기존 로컬 JavaScript 키 사용, REST 키 추가 없음.
- 공백·일부 구분 문자와 서울청년센터/청년센터 표기 정규화 후 같은 이름, 같은 시도·구, 유효 좌표인 유일한 후보만 수용. 후보 중복 또는 다음 페이지가 있으면 자동 선택하지 않음.
- 주소 조회 API 오류는 장소 미존재로 취급하지 않음. 검색 오류·시간 초과에는 기존 실패 안내와 재시도 유지.
- 결과 주소·좌표·카카오맵 상세 링크는 지도에만 보완 표시하고 ‘카카오맵 장소 정보로 보완’ 출처 표시. 기관 소개·프로그램 데이터는 변경하지 않음.
- 거리순 계산도 동일 resolver 사용. 요청 동시성 기존 4개 유지, 성공 결과와 진행 중 요청 메모리 공유. 결과는 DB·로컬 저장소에 영구 저장하지 않음.

검증: verify-center-place.mjs의 SDK 대역으로 공식 주소 우선/누락 주소 보완/주소 0건/다른 지역·이름 배제/모호·잘린 검색 배제/잘못된 좌표/캐시/API 오류·재시도 검사 통과. 기존 center-address, center-distance, center-display, schedule-display 검사와 TypeScript+Vite 빌드 통과. 기존 청크 크기 경고 유지.

미검증: 현재 브라우저 조작 도구가 없어 실제 SDK 외부 검색 결과, 화면 지도·모바일 재검증은 수행하지 못함. SDK 대역 검사를 실제 API 통과로 간주하지 않음. 기존 로컬 키와 도메인 설정은 변경하지 않음.

공식 계약: https://apis.map.kakao.com/web/documentation/#services_Places_keywordSearch

## 상세 표시 정리

- 프로그램 개수 0/미제공은 빈 자리로 두고 부재·수집 문구를 출력하지 않음. 양수인 모집 중 개수만 표시.
- 출처 행에는 ‘공식 홈페이지’ 링크만 표시. 홈페이지가 없으면 공식 안내 source URL 사용. 수집 확인일·중복 출처 문구 제거.
- 실제 제공된 운영시간만 표시하고 없으면 운영시간 행 자체 숨김. 카카오맵 링크로 위치·운영시간 확인 가능.
- 카카오 공식 장소 검색 응답에는 영업시간 필드가 없음. 따라서 영업시간을 SDK에서 받아 표시했다고 주장하지 않음. 실제 시간의 추가 수집은 별도 필요.
- 관련 React 렌더 검사에서 미수집 문구 부재, 운영시간 유무별 행 표시, 출처 링크/카카오맵 링크 확인.

## 공식 사이트 상세 수집으로 대체

후속 사용자 교정: 카카오맵 영업시간 부재를 이유로 공식 사이트 운영시간까지 숨겨 두어서는 안 됨. backend의 공식 센터 공간소개·공지 수집을 연결하여 서울청년센터 17곳의 실제 운영시간·소개·이용방법과 최근 공지를 표시함. 출처 라벨은 ‘공식 홈페이지’로 교체하고 링크를 해당 행에 배치. 공지 제목/등록일/공식 원문 링크 제공, 전체 공지 링크 유지. 실제 Vite→API 응답을 React로 렌더하여 중구 21:30 운영시간, 홈페이지 라벨, 실제 공지 제목을 확인했고 모든 프로그램 0개 센터에서 수집/0개 문구 부재 확인. 브라우저 클릭·시각 검증은 도구가 없어 여전히 미검증.
