# JOY 디자인 기준 — 현재 작업 기준

업데이트: 2026-11-18

서비스명은 둘셋(Dos Tres)이며 조이(JOY)는 AI 비서·캐릭터 이름이다. 공식 23 섬 로고와 로고 색상은 [둘셋 브랜드 기준](BRAND.md)을 따른다. 아래는 캐릭터와 공통 UI의 기준이다.

캐릭터의 기본 형태·얼굴·종이 질감·파란 스카프는 [확정 참고 시트](references/joy-character-sheet.png)를 기준으로 한다. 아래 팔레트는 현재 공통 기준으로 고정하며 명시적인 변경 요청이 있을 때만 함께 갱신한다. 시트 안의 색상 견본은 정확한 HEX 명세가 아니다.

## 컬러 팔레트 — 공통 기준

| 컬러 | HEX | 사용처 |
|---|---|---|
| 페이퍼 아이보리 | #F7F1EB | 조이 몸체, 따뜻한 배경 |
| 조이 블루 | #7799E2 | 스카프, 주요 버튼·선택 상태 |
| 페리윙클 | #8385DC | 보조 포인트 |
| 라이트 라벤더 | #E5E2FF | 태그, 말풍선, 카드 강조 배경 |
| 잉크 네이비 | #393653 | 제목, 본문, 아이콘 |
| 치크 코랄 | #F5AB9D | 볼, 감정 표현 |
| 조이 옐로 | #FFD05C | 반짝임, 작은 강조 요소 |
| 소프트 화이트 | #FFFEFC | 기본 화면·카드 배경 |

## 캐릭터 유지 규칙

첨부된 조이 원본 이미지를 디자인의 최우선 기준으로 사용한다.
삼각형 종이접기 머리, 접힌 몸체, 종이 질감, 파란 스카프, 타원형 눈, 코랄빛 볼과 입, 부드러운 그림자를 유지한다.
형태와 신체 비율, 얼굴 배치, 재질 표현을 유지하며 표정·포즈·변신만 확장한다.
종이배·종이비행기·지도 변신에도 같은 종이 질감과 얼굴 표현을 적용한다.
기존 원본 이미지는 그대로 사용한다. 이미지 내부의 빛과 그림자는 유지하고, HEX는 UI 및 신규 디자인의 기준색으로 적용한다.

## 화면 적용

기본 화면은 소프트 화이트, 따뜻한 영역은 페이퍼 아이보리를 사용한다.
조이 블루를 주요 행동에 사용하고 라이트 라벤더를 보조 배경에 사용한다.
본문과 버튼 글자는 배경과 읽기 쉬운 대비를 확보한다. 밝은 조이 블루 위에는 잉크 네이비 글자를 우선 사용한다.

## 기준 우선순위와 변경

서비스명·로고 원본·로고 색상: [둘셋 브랜드 기준](BRAND.md). 기존 UI와 캐릭터 색상을 로고 색상으로 일괄 치환하지 않는다.

1. 캐릭터 외형·재질·비율·변신: [확정 원본 시트](references/joy-character-sheet.png).
2. UI의 정확한 색상·공통 스타일: 이 문서.
3. 에셋 경로·제작 상태: [asset-manifest.json](asset-manifest.json).

이전 기본·마스터 시트는 과거 참고 자료이며 신규 디자인에 혼용하지 않는다. 이미지의 조명·음영·질감을 HEX로 치환하거나 원본을 재색칠하지 않는다. 색상 변경 요청 시 이 문서, 공통 CSS 변수, 관련 안내를 함께 갱신한다. 각 페이지에서 임의 색상을 추가하지 않는다.

## 공통 UI 규칙

아래는 이후 화면 개선에 적용할 기준이다. 현재 코드에 모두 적용되었다는 뜻은 아니다. 첫 화면 개선 시 공통 CSS 변수와 컴포넌트를 정리하고 이후 화면에서 재사용한다.

| 항목 | 공통 기준 |
|---|---|
| 배경·표면 | 기본 #FFFEFC, 따뜻한 보조 영역 #F7F1EB, 강조 배경 #E5E2FF. 페이지 전체에 과도한 장식·그라데이션을 반복하지 않음 |
| 행동·선택 | 주요 행동 #7799E2, 보조 포인트 #8385DC. 같은 행동에 같은 색·버튼 형태 사용 |
| 글자 | 기본 #393653. 밝은 배경에서 대비 확인. 비활성·보조 글자도 읽을 수 있는 대비 유지 |
| 폰트 | 현재 프로젝트의 한국어 본문 폰트 스택을 공통 사용. 화면마다 새 폰트 추가 금지 |
| 글자 크기 | 본문 16px·줄높이 1.5 기준, 보조 14px, 섹션 제목 20–24px, 페이지 제목 28–32px. 모바일 제목은 공간에 맞게 조정 |
| 간격 | 4px 배수: 4·8·12·16·24·32·48. 같은 역할의 카드 패딩·섹션 간격 통일 |
| 모서리 | 버튼·입력 12px, 카드 16px, 칩은 pill. 같은 역할에서 임의 반경 혼용 금지 |
| 그림자·테두리 | 공통 변수로 관리하는 약한 그림자와 얇은 테두리 사용. 강한 그림자 중첩 금지 |
| 버튼 | 기본 높이 44px 이상. 화면의 핵심 행동 하나를 시각적으로 우선. 보조·위험 행동 구분. hover·focus·disabled·loading 상태 제공 |
| 입력·선택 | 항상 이해 가능한 레이블 제공. 선택·오류·도움말 표현 통일. 색만으로 상태 구분 금지 |
| UI 아이콘 | lucide-react, 기본 24px·strokeWidth 2. 작은 인라인 아이콘만 16–20px. 브랜드 일러스트와 역할 구분 |
| 캐릭터·일러스트 | 확정 시트의 종이접기 질감·비율·부드러운 그림자 유지. 본문·버튼·정책 정보를 가리지 않는 보조 역할 |
| 문구 | 짧고 쉬운 한국어, 사용자 안내는 ‘~해요’체. 같은 기능의 이름·동사 통일, 실제 완료 여부를 정확히 표현 |
| 공통 상태 | 로딩·빈 결과·오류·성공에 같은 구조와 안내 방식 사용. 필요한 다음 행동을 텍스트로 제공 |
| 반응형·접근성 | 모바일 가로 넘침 방지, 고정 높이로 글자 자르지 않기, 키보드 포커스 표시, 터치 영역 44px 이상. 일반 글자 대비 4.5:1, 큰 글자·핵심 UI 경계 3:1 확보 |

성공·오류 등 의미 색상이 추가로 필요하면 공통 의미 토큰으로 한 번 정의하고 여러 화면에서 공유한다. 코랄·옐로 등 장식색을 오류나 경고의 유일한 표식으로 사용하지 않는다.

## 설계 자율성

화면 레이아웃·정보 순서·카드 구성·문구·캐릭터 위치와 크기는 서비스 목적에 맞게 자율 설계한다. 시트의 패널 배치와 제목 장식을 화면에 그대로 복제할 필요는 없다. AI가 사용자의 다음 행동을 어떻게 돕는지 먼저 보이게 하고, 청년 대상의 단정하고 친근한 분위기를 유지한다. 공통 규칙을 지키면서 요청받은 화면부터 순차 개선한다.

## 화면 수정 시 확인

- 확정 시트 하나를 참고했고 과거 시트나 새 팔레트를 혼용하지 않았는가.
- 같은 역할의 컴포넌트·폰트·색·간격·상태 표현을 재사용했는가.
- 데스크톱·모바일에서 가독성·줄바꿈·키보드 포커스·대비를 확인했는가.
- 새 에셋의 실제 파일·경로·제작 상태를 manifest에 정확히 기록했는가.
- UI 코드 변경 시 빌드와 해당 화면 동작을 확인했는가.


## 홈 디자인 브랜치에서의 적용

2026-11-21 사용자 요청에 따라 홈에서 브랜드 초록·연두의 역할을 확대하는 디자인을 검토한다. `home-page.css`는 `.home-design-shell` 아래의 홈 토큰을 정의하며 다른 화면의 기존 색상 변수는 변경하지 않는다. 조이·종이 재질·파란 스카프는 원본을 유지하고, 대화 입력은 조이 블루를 사용한다. [홈 디자인 기록](home-paper-village.md). 이 실험은 전체 페이지 팔레트 변경이나 최종 디자인 승인으로 간주하지 않는다.
