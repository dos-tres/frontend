# 둘셋 세계관 일러스트 (섬 → 다리 → 마을)

## 목적과 상태
- 홈의 입력 중심 레이아웃 아래에 나타나는 클릭 가능한 세계관을 위한 **독립 SVG 일러스트 3개**.
- 2026-11-18 사용자 피드백에 따라, `sunbousai.jp`의 따뜻하고 연결된 풍경 경험을 참고하되 **원본을 모사하지 않고 둘셋용으로 새로 구성**했다.
- 본 에셋은 코드로 저작한 벡터 일러스트 SVG이며, 대화 중 시안으로 생성한 수채화 PNG와 동일한 원본 파일은 아니다. PNG가 필요하면 디자인 확정 후 이 SVG에서 투명 배경으로 내보낸다.
- 캐릭터 조이(JOY)의 고유 이미지와 서비스 로고는 **변경하지 않는다**.

## 에셋 위치와 역할
| 파일 | 역할 | 클릭 이동 |
| --- | --- | --- |
| `public/illustrations/world/island.svg` | 얼굴·캐릭터 없는 초록 섬, 깃발·꽃·물결 | 나의 상태/성향(`profile`) |
| `public/illustrations/world/bridge.svg` | 물 위의 둥근 나무 다리, 꽃·수풀 | 청년정책(`policy-list`) |
| `public/illustrations/world/village.svg` | 파스텔 지붕의 작은 집 세 채, 나무·길 | 참여 기록(`records`) |

## 시각 기준
- 둘셋 브랜드: 초록 `#426B4A`, 연두 `#91AE72`.
- 조이와 공통 UI: 종이 아이보리 `#F7F1EB`, 블루 `#7799E2`, 라벤더 `#E5E2FF`, 네이비 `#393653`, 코랄 `#F5AB9D`, 옐로 `#FFD05C`.
- 자연스럽고 따뜻한 수채화풍을 목표로 하며, SVG는 작은 크기에서도 가독성을 유지하는 **단순화된 벡터 표현**이다.
- 아이콘에는 얼굴·조이 캐릭터·교통수단을 넣지 않는다. 배·비행기·차는 추후 조이 변신 상태로 따로 제작한다.
- 웹 텍스트는 이미지에 포함하지 않고 React/HTML로 제공한다.

## 적용 및 애니메이션
- `src/App.tsx`의 `journey-world` 영역에서 SVG를 `img`로 사용한다.
- 배경의 물결·구름은 `src/styles.css`의 CSS로 움직인다. 스크롤로 영역이 보이면 단계별 등장하고, 마우스/키보드로 선택하면 약하게 떠오른다.
- `prefers-reduced-motion`에 따라 움직임을 중단한다.
- 실 UI가 없는 경우를 꾸며내지 않으며 클릭은 **이미 존재하는 페이지**만 연다.
- 로고·기존 조이 원본·홈 입력창·우측 미니 배너는 이 작업 범위에서 변경하지 않는다.
