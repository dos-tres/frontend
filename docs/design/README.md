# 디자인·이미지 기준

## 목적
청년 정책·센터 프로그램을 찾아 활용하도록 돕는 둘셋(Dos Tres)의 프론트엔드를 화면별로 구체화한다. AI 비서·캐릭터 이름은 조이(JOY)이며 종이접기 변신과 섬·다리·마을을 공통 시각 언어로 사용한다. 서비스명과 공식 23 섬 로고는 [둘셋 브랜드 기준](BRAND.md)을 따른다.

## 기준 자료와 실제 에셋
| 경로 | 내용 |
|---|---|
| public/brand/ | 확정 둘셋 로고 3종의 SVG·PNG 원본 |
| docs/design/BRAND.md | 이름·공식 로고·로고 색상·사용처 |
| docs/design/references/ | 캐릭터 기준 이미지·참고 화면·색상 자료 |
| docs/design/asset-manifest.json | 필요한 이미지와 제작 상태 |
| src/assets/characters/ | 실제 사용할 조이 포즈 PNG |
| src/assets/icons/ | 서비스 전용 SVG 또는 투명 PNG |
| assets/images.json | v1에 포함된 기존 PNG 6개 원본 |
| scripts/restore-assets.mjs | 기존 PNG 자동 복원 |

새 폴더는 첫 실제 파일과 함께 생성한다. 기존 v1 이미지는 npm install 후 src/assets/에서 확인한다. 기존 복원 이미지를 이동하거나 변경하려면 코드 import도 함께 수정한다.

## 조이 일관성
- 현재 색상·캐릭터 규칙은 [JOY 디자인 기준](JOY_design_guidelines.md)을 따른다.
- 기본 형태·얼굴·종이 질감·파란 스카프는 [확정 캐릭터 참고 시트](references/joy-character-sheet.png)를 우선한다. 전체 시트는 참고 자료이며 개별 투명 PNG는 아직 준비되지 않았다.
- [이전 기본 시트](references/joy-character-base.png)와 [이전 마스터 시트](references/joy-style-master.png)는 과거 참고 자료다. 신규 제작 시 혼용하지 않고 확정 시트 하나를 첨부한다. UI의 정확한 HEX는 디자인 기준 문서를 따른다.
- 기존 src/assets/joy.png와 characters의 포즈 파일은 화면 구현에 활용할 수 있다.
- 동일 캐릭터의 실루엣·얼굴·접힌 면·색·재질을 유지한다.
- 새 포즈는 기준 이미지를 첨부해 제작한다. 텍스트 설명만으로 매번 새 캐릭터를 만들지 않는다.
- 성인 청년에게 친근한 분위기, 단정한 종이 재질과 부드러운 입체감.
- 배경 투명, 캐릭터 전체가 잘리지 않는 구도, 일정한 여백.
- 기본 출력은 1024×1024 PNG. 실제 화면에서는 CSS 크기를 조정한다.
- UI 색상은 JOY_design_guidelines.md의 공통 기준 팔레트를 따른다. 이미지 원본을 팔레트에 맞춰 재색칠하지 않는다.

## 아이콘
검색·닫기·메뉴·설정·화살표·캘린더 등 일반 조작은 lucide-react를 사용한다. 기본 24px, 같은 선 두께와 색상 체계를 유지한다. 종이배·다리·섬 같은 서비스 전용 요소만 별도 제작한다. 단순하고 정확한 아이콘은 SVG로 작성하고, 복잡한 입체 일러스트는 투명 PNG를 사용한다. 장식 에셋을 기능 버튼의 유일한 설명으로 사용하지 않는다.

## 생성 요청 템플릿
기준 조이 이미지를 첨부하고 다음 문장에서 대괄호 부분만 바꾼다.

> 첨부한 조이와 동일한 캐릭터로 [생각하는 포즈]를 만들어줘. 얼굴, 실루엣, 종이접기 구조, 색상, 재질을 유지해줘. 성인 청년 지원 서비스용으로 단정하고 친근하게 표현해줘. 투명 배경의 1024×1024 PNG, 캐릭터 전체와 일정한 여백, 문자·로고·워터마크 없음. 사용 위치는 [AI 응답 대기 영역]이야.

## 제작·적용 순서
1. 기준 이미지와 사용할 포즈를 확인한다.
2. 한 포즈를 생성하고 기준과 비교한다.
3. 파일명을 소문자 kebab-case로 지정해 실제 에셋 폴더에 저장한다.
4. asset-manifest.json에 경로·상태·제작 정보를 기록한다.
5. 해당 화면에 적용하고 비율·여백·모바일 크기를 확인한다.
6. npm run build 후 커밋한다.

## 확정 범위와 설계 자율성
캐릭터의 정체성은 확정 시트를 기준으로 유지한다. 팔레트는 현재 공통 기준으로 고정하며 명시적인 변경 요청이 있을 때만 함께 갱신한다. 화면 레이아웃·문구·정보 순서·카드 구성·캐릭터 배치와 크기는 확정되지 않았다. 서비스 목적, 정보 우선순위, 가독성, 접근성, 반응형 기준으로 자율적으로 설계한다. 확정 시트는 UI 배치 시안이 아니다.

일반 조작 아이콘은 lucide-react, 브랜드 일러스트는 종이접기 스타일을 사용한다. 확정 시트의 배·비행기·지도는 형태 참고 예시이며 독립된 투명 아이콘 파일로 제공되는 것은 아니다.

## 화면 간 공통 UI
색상·폰트·크기·간격·모서리·그림자·상태 표현은 [공통 UI 규칙](JOY_design_guidelines.md#공통-ui-규칙)을 따른다. 같은 역할의 버튼·입력·태그·카드는 공통 컴포넌트와 CSS 변수를 재사용한다. 홈을 시작으로 수정하는 화면에 순차 적용하며, 이 문서 갱신 자체가 기존 화면의 적용 완료를 뜻하지 않는다.
