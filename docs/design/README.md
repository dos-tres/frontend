# 디자인·이미지 기준

## 목적
청년 정책·센터 프로그램을 찾아 활용하도록 돕는 AI 에이전트의 프론트엔드를 화면별로 구체화한다. 캐릭터 이름은 조이이며 종이접기 변신과 섬·다리·마을을 공통 시각 언어로 사용한다. 서비스명은 별도 확정 전까지 기존 화면 표기를 유지한다.

## 기준 자료와 실제 에셋
| 경로 | 내용 |
|---|---|
| docs/design/references/ | 캐릭터 기준 이미지·참고 화면·색상 자료 |
| docs/design/asset-manifest.json | 필요한 이미지와 제작 상태 |
| src/assets/characters/ | 실제 사용할 조이 포즈 PNG |
| src/assets/icons/ | 서비스 전용 SVG 또는 투명 PNG |
| assets/images.json | v1에 포함된 기존 PNG 6개 원본 |
| scripts/restore-assets.mjs | 기존 PNG 자동 복원 |

새 폴더는 첫 실제 파일과 함께 생성한다. 기존 v1 이미지는 npm install 후 src/assets/에서 확인한다. 기존 복원 이미지를 이동하거나 변경하려면 코드 import도 함께 수정한다.

## 조이 일관성
- 기존 src/assets/joy.png를 임시 기준으로 사용한다. 최종 기준 이미지는 references에 넣고 파일명을 아래 자료 목록에 기록한다.
- 동일 캐릭터의 실루엣·얼굴·접힌 면·색·재질을 유지한다.
- 새 포즈는 기준 이미지를 첨부해 제작한다. 텍스트 설명만으로 매번 새 캐릭터를 만들지 않는다.
- 성인 청년에게 친근한 분위기, 단정한 종이 재질과 부드러운 입체감.
- 배경 투명, 캐릭터 전체가 잘리지 않는 구도, 일정한 여백.
- 기본 출력은 1024×1024 PNG. 실제 화면에서는 CSS 크기를 조정한다.
- 정확한 브랜드 색상 수치는 기준 자료 확정 후 기록한다. 현재 임의의 색상 코드를 공식 색으로 지정하지 않는다.

## 아이콘
검색·닫기·메뉴·설정·화살표·캘린더 등 일반 조작은 lucide-react를 사용한다. 기본 24px, 같은 선 두께와 색상 체계를 유지한다. 종이배·다리·섬 같은 서비스 전용 요소만 별도 제작한다. 단순하고 정확한 아이콘은 SVG로 작성하고, 복잡한 입체 일러스트는 투명 PNG를 사용한다. 장식 에셋을 기능 버튼의 유일한 설명으로 사용하지 않는다.

## 생성 요청 템플릿
기준 조이 이미지를 첨부하고 다음 문장에서 대괄호 부분만 바꾼다.

> 첨부한 조이와 동일한 캐릭터로 [생각하는 포즈]를 만들어줘. 얼굴, 실루엣, 종이접기 구조, 색상, 재질을 유지해줘. 성인 청년 지원 서비스용으로 단정하고 친근하게 표현해줘. 투명 배경의 1024×1024 PNG, 캐릭터 전체와 일정한 여백, 문자·로고·워터마크 없음. 사용 위치는 [AI 응답 대기 영역]이야.

## 제작·적용 순서
1. 기준 이미지와 사용할 포즈를 확인한다.
2. 한 포즈를 생성하고 기준과 비교한다.
3. 파일명을 소문자 kebab-case로 지정해 실제 에셋 폴더에 저장한다.
4. asset-manifest.json에 경로·상태·제작 정보를 기록한다.
5. 해당 화면에 적용하고 비율·여백·모바일 크기를 확인한다.
6. npm run build 후 커밋한다.

## 기준 자료 목록
현재 별도로 추가된 기준 자료는 없다. v1의 기존 조이를 임시 기준으로 사용한다. references에 자료를 넣을 때 references/README.md의 표를 갱신한다.
